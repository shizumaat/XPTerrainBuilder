# HISTORICAL RECORDS — not guidance

Everything in this directory is a campaign artifact from the
prototype/gated era (specs, adjudication tails, round verdicts). It is
preserved as engineering history and evidence provenance. It is NOT a
description of the current system: designs here were repeatedly
superseded, and several documents record their own falsification.

THE LIVING LAW IS docs/RULINGS.md (owner canon, updated in the same
commit as the change). The living behavior is the code and its twins.
The living tooling is tools/INDEX.md. Do not implement from, cite as
current, or "fix" documents in this directory; when history is needed,
quote it AS history with its date.
