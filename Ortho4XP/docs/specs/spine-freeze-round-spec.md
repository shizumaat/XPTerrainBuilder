## The design (the Ruling-54 pattern, generalized)

Phase-A spine values stop freezing as base_hard into the full
projections. Under gate `O4_SPINE_YIELD_HARD` (default "0"): spine
nodes enter every downstream projection as YIELD-HARD members — held at
their phase-A values wherever the full graph's law permits, movable by
the projection ONLY where law demands, every movement reported
(write-only: node, phase-A value, shipped value, the binding
constraint) through the existing forensics channel. The mechanism
exists (Ruling 54's yield_hard membership + the declared-conflict
path); this round extends its membership, it does NOT invent machinery.
Runway profile nodes and CIFP-anchored values remain base_hard (they
are law, not phase-A estimates — enumerate the preserved set
explicitly: runway_nodes, G.runway_anchor, CIFP-derived, seam pins).
