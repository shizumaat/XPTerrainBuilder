# Lane brief packs

One file per lane, generated by `tools/brief_pack.py`, committed with the
dispatch. A lane reads its pack FIRST and WHOLE, then `.claude/agents/lane.md`;
it does not grep the spec, RULINGS or INDEX monoliths for what the pack
already carries (owner 2026-09-13: lanes were spending 115k–170k fresh tokens
and 12–16 turns slicing those before their first edit).

    tools/brief_pack.py --lane v2foo --base <main sha> \
        --spec '§37 (6)' --rulings 13aj 13ab --index road_terrain_conformance \
        --frames KCLT --notes notes.md --bars bars.md \
        --files Ortho4XP/src/auto_patch_v2/constraints/roads.py \
        --avoid Ortho4XP/src/auto_patch_v2/constraints/eat.py \
        > docs/briefs/v2foo.md

The pack names its base sha. Main moves; the lane still merges main first.
The Agent launch prompt then reduces to: the lane name, the pack path, and
anything the session wants to say that is not law.

Follow-up rounds on the same area RESUME the lane that did the round
(`SendMessage`) instead of spawning a fresh one — a resumed lane pays no
startup.
